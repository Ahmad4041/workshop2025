"# GitHub Commands for Practice" 
"This README contains basic GitHub commands for developers." 
"" 
"### Cloning a Repository" 
"To clone a repository from GitHub:" 
"```bash" 
"git clone https://github.com/Ahmad4041/workshop2025.git" 
"```" 
"" 
"### Creating a Branch" 
"To create a new branch:" 
"```bash" 
"git checkout -b <branch_name>" 
"```" 
"" 
"### Switching Branches" 
"To switch to an existing branch:" 
"```bash" 
"git checkout <branch_name>" 
"```" 
"" 
"### Adding Changes" 
"To stage files for commit:" 
"```bash" 
"git add <file_name>" 
"```" 
"Or to stage all changes:" 
"```bash" 
"git add ." 
"```" 
"" 
"### Committing Changes" 
"To commit staged changes:" 
"```bash" 
"git commit -m \"Your commit message\"" 
"```" 
"" 
"### Pushing Changes" 
"To push changes to GitHub:" 
"```bash" 
"git push origin <branch_name>" 
"```" 
"" 
"### Pulling Changes" 
"To pull changes from GitHub to your local repository:" 
"```bash" 
"git pull origin <branch_name>" 
"```" 
"" 
"### Viewing the Status" 
"To see the status of your repository:" 
"```bash" 
"git status" 
"```" 
"" 
"### Viewing Commit History" 
"To view the commit history:" 
"```bash" 
"git log" 
"```" 
"" 
"### GitHub Branching Strategy" 
"1. **main**: The main branch, which should always be stable." 
"2. **feature branches**: Used to develop new features or fixes." 
"" 
"Remember to always create a branch from main for each feature or fix to keep things organized."
